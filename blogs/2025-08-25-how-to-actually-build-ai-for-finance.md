“AI” has become the most overused label in enterprise software. Every week a new startup announces it has cracked the code by wrapping ChatGPT in a glossy UI or by automating some Excel workflow. It makes for slick demos and snappy press releases, but it doesn’t actually change how financial firms make decisions.
